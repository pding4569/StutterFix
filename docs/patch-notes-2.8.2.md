## 2.8.2 에서 바뀐 것

- **히트음 예약 묶기가 0.5초마다 내던 '틱' 소리를 고쳤습니다.** 2.8.0·2.8.1 의 묶기는 히트음을 0.5초 조각으로 나눠 이어 틀었는데, 조각이 이어지는 자리에서 파형이 갑자기 끊겨 딱 하는 잡음이 날 수 있었습니다. 이제 조각 앞뒤를 겹쳐 부드럽게 이어 붙입니다. HELLO 2026에서 곡 소리를 끄고 게임이 내보내는 소리를 녹음해 조각 이음매 47곳을 분석했습니다(모드 안 진단 도구로 한 분석이며 귀로 비교한 것은 아닙니다). 이음매 순간의 파형 급변은 2.8.1 에서 같은 조각 안 다른 곳의 중앙값 **7.3배**(이음매 79%가 상위 5%보다 큼)였고 2.8.2 에서는 **0.8~0.9배**(상위 5% 초과 4%, 우연 수준)로 사라졌습니다. 히트음이 시작하는 시각은 그대로입니다(절대 시각 어긋남 1e-9 샘플 이하, 합성 PCM 합 오차 1.2e-7 이하).
- **죽은 직후 히트음이 남지 않도록 한 번 더 막았습니다.** 죽음 처리(`OnPlayerDied`·`Fail2Action`)에서도 묶기를 멈추고, 실패 상태에서는 남은 예약을 놓고 이미 예약된 소리를 바로 끊습니다. HELLO 곡 중간에 죽으면 재생 중인 소리가 **52개 → 1개(게임 자체 소리 하나) → 3초 안에 0개**, 처음에 죽어도 1개 → 0개였습니다.
- **Silentroom - 1KXYZØ 5225번 타일 근처에서 큰 타일이 투명해지던 문제를 고쳤습니다**(에디터 재생). 타일 이동 직접 처리(FloorAnim)가 화면 밖 타일 끄기(TileCull)에 이동을 알리지 않아, 화면 밖이라 꺼 둔 타일이 효과로 화면에 들어와도 꺼진 채 남았습니다. 2.8.1 과 제보자 설정 222개로 에디터 재생 3번 모두 재현, 수정 뒤 3번 모두 정상이었습니다.
- **`메모리 정리 미루기`를 끄면 곡 시작·끝 처리가 통째로 빠지던 문제를 고쳤습니다.** 셰이더 미리 준비, 곡 중 물리 중지, 저사양 설정 같은 곡 수명 처리가 그 설정과 함께 꺼지고 있었습니다. 설정을 끈 채 HELLO 를 시작하면 2.8.1 은 곡 시작 처리 로그가 하나도 없었고 2.8.2 는 켠 때와 같은 처리가 남습니다.
- **윈도우가 아닌 운영체제(리눅스·맥의 원래 유니티)에서는 모드가 아무것도 설치하지 않고 안내만 합니다.** 이전에는 불러오는 도중 오류로 죽었습니다. 윈도우 밖에서는 직접 시험하지 못했고, Wine·Proton 은 윈도우로 인식돼 그대로 동작합니다.
