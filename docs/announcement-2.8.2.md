# StutterFix 2.8.2 업데이트
- **히트음 '틱' 소리 수정**: 2.8.0·2.8.1 의 히트음 예약 묶기가 0.5초 조각이 이어지는 자리에서 내던 딱 하는 잡음을 없앴습니다(녹음 분석: 이음매 파형 급변 7.3배 → 0.8~0.9배).
- **화면 밖 파티클 멈추기 기본 꺼짐으로 되돌림**: 일부 맵에서 화면 안 파티클(예: eLadia 타일 주변 검은 효과)까지 없애고, 메모리 정리 미루기를 켜고 끌 때 이펙트가 달라 보이던 원인이었습니다.
- **죽은 직후 히트음 보호 보강**: 죽음·실패 처리에서 남은 예약을 바로 끊습니다(곡 중 죽으면 재생 중 52개 → 1개 → 0개).
- **Silentroom - 1KXYZØ 큰 타일 투명 문제 수정**(에디터 재생).
- **`메모리 정리 미루기`를 끄면 곡 시작·끝 처리가 빠지던 문제 수정**, **윈도우 아닌 OS에서 불러오기 오류 대신 안내만**.
자동 업데이트 설치 알림 후 게임을 완전히 껐다 켜 주세요. 문제는 설정 창의 `로그 내보내기`로 만든 ZIP을 보내 주세요.
