# 테스터 2.5.3.2 확인할 것

게임을 완전히 끈 뒤 `StutterFix-2.5.3.2-tester.zip`을 설치합니다. 네이티브 DLL도 바뀌어 게임 재시작이 필요합니다.

독점 전체 화면 전환과 프레임 생성의 해제 순서, 원래 Present 연결의 수명을 고쳤습니다. 주사율 맞춤·2~8배와 화면 효과 값은 유지하며 기능은 새 설정에서 기본 꺼짐입니다.

- 곡 재생 중 독점 전체 화면을 켰다가 끄기. 빠르게 다시 켜고 꺼도 종료되거나 멈추지 않는지.
- 프레임 늘리기 끔 / 주사율 맞춤 / 4배에서 각각 확인하기.
- 독점 전체 화면에서 Alt+Tab·최소화 후 복귀하기. 검은 화면이 남거나 게임이 종료되는지.
- 곡 완료 후 다른 맵 열기, 게임 종료 후 다시 시작하기.
- 화면 효과 강도 숫자 입력과 기존 설정 저장이 유지되는지.

문제가 있으면 맵·곡 시간·프레임 생성 모드·전체 화면 켜기/끄기/복귀 중 어느 동작인지와 `Player.log`를 함께 남겨 주세요.
전환 순간의 모드 재설정과 평상시 곡 재생의 끊김은 나눠 기록해 주세요. 이 버전의 새 성능/표시 지연 측정은 확인 안 됨입니다.
