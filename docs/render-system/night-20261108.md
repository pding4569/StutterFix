## 4. turbo 나누기 (2판 평균)

| 설정 | Exit | Windflower |
|---|---:|---:|
| turbo 없음 | 316.6 / 316.7 | 174.3 / 176.6 |
| turbo 전체 | 327.7 | 181.5 |
| turbo safe (UI 마스크 잘라내기 건너뛰기·플래시 판 숨기기 뺌) | 325.6 / 326.3 | 180.8 / 176.3 |
| **turbo safe2 (safe + 카메라 깊이 텍스처 유지)** | **325.3** | 176.2 |

- **safe2를 고른 이유:** 카메라 모션 블러(`CameraMotionBlur`)는 켜질 때 한 번만 깊이 텍스처를 켠다. turbo가 깊이 텍스처를 끄면 그 효과가 깊이 없이 돌 수 있다. 깊이를 지켜도 Exit 이득은 그대로라 safe2가 맞다.
- **Windflower:** turbo 이득이 판에 따라 0~4%다.
- **제품 반영 전 남은 일:** 렌더러 플래그를 끌 때 되돌리기, 모든 렌더러 훑기를 곡 시작이 아니라 맵 불러오기에서 하기, 일시정지 때 PausePlanets 카메라 다시 켜기.
