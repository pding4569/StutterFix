# StutterFix 2.7.1 업데이트

- **프레임 늘리기(실험)** 고정 2~8배가 더 고르게: 같은 그림이 반복되거나 잠깐 멈추던 것을 고쳤습니다(60 FPS 제한 4배에서 멈춘 그림 35.7% -> 0%).
- 공 크기·검은 테두리를 고쳤고, 게임 창 위에 다른 창(데스크톱 캐릭터 등)이 있으면 알려 줍니다.
- 음악 반응 계산 끄기가 새 설치부터 기본 켬(프레임당 0.07ms).
- 내장 그래픽에서 큰 이미지 자동 한도를 시스템 RAM 기준으로 잡습니다.
- **새 기능은 전부 기본 꺼짐**입니다.

자동 업데이트를 켜 둔 분은 설치 알림 후 게임을 다시 켜면 적용됩니다(프레임 늘리기는 꼭 다시 켜야 합니다).
수동 다운로드·상세 패치노트: https://github.com/pding4569/StutterFix/releases/tag/v2.7.1
문제가 있으면 설정 창의 `로그 내보내기`로 만든 ZIP을 보내 주세요.
