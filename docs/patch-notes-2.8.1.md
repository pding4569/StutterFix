## 2.8.1 에서 바뀐 것

- **죽은 뒤에도 히트음이 계속 들리던 문제를 고쳤습니다.** 2.8.0 에서 기본 켬이 된 히트음 예약 묶기가, 죽는 순간 아직 안 들려준 히트음을 게임에 돌려줘서 게임이 앞으로 5초 치 히트음을 다시 예약했고(HELLO 에서 226개), 상태가 실패로 바뀌기 전 한 프레임 사이에 예약된 소리가 죽은 뒤 3~4초 동안 이어졌습니다. 이제 죽음·다시 하기·나가기에서는 남은 히트음을 돌려주지 않습니다. 같은 시험에서 죽은 직후 재생 대기 중인 소리가 **226개 → 1개**(묶기를 끈 기준판과 같음)였고, 곡 중간(묶기 가동 중)에서 죽어도 1.5초 안에 0개가 됐습니다. 곡을 끝까지 깬 경우의 마지막 소리는 기존대로 이어서 납니다.

히트음 예약 묶기는 저사양 페이지에서 끌 수 있습니다. 자동 업데이트 설치 알림 후 게임을 완전히 껐다 켜 주세요.
