# 테스터 2.8.1.1 확인할 것 (3.0.0 후보: GPU 장식)

게임을 완전히 끈 뒤 `StutterFix-2.8.1.1-tester.zip`을 설치합니다(UMM "Install Mod"). 네이티브 DLL이 바뀌어 게임 재시작이 필요합니다.

새 기능 **GPU 장식**(설정창의 "GPU 장식" 페이지, 기본 켜짐)이 장식 계산을 그래픽카드로 넘깁니다. 장식이 많은 맵(Arche 같은 2만 개 이상)에서 FPS가 오르고 무거운 구간의 끊김이 줄어듭니다.
화면·연출은 원래 게임과 같아야 합니다. 달라 보이는 곳이 있으면 알려 주세요.

## 꼭 봐 주세요
- 곡 시작: 시작 키를 누른 뒤 카운트다운 중에 멈칫하는지(켜는 약 150ms를 키 누르기 전으로 옮겼습니다).
- **죽었을 때**: 죽는 순간 프레임이 멈추는지, 죽은 뒤 **히트음이 남아 들리는지**(곡 중간에 죽는 경우 포함).
- 다시 하기: 로딩 시간이 이전보다 어떤지(첫 다시 하기 0.8초 멈춤을 없앴고, 준비를 1.17초 → 0.23초로 줄였습니다).
- 곡 끝(완주): 마지막 타일에서 멈칫하는지, 결과 화면에서 장식이 이상한지.
- 에디터: 중간부터 재생 시작(곡 0.6초에 약 190ms 멈춤이 남아 있습니다), 편집으로 나간 뒤 타일을 눌렀을 때의 끊김.
- 맵을 **처음 열 때** 로딩이 이전보다 약 1~6초 길 수 있습니다(장식 준비 5.9초 + 정리 0.8초, Arche 기준).

## 알려진 한계
- 에디터 재생 시작 때 약 190ms 한 프레임 멈춤, 다시 하기를 누르는 순간 최대 약 60ms.
- 다른 모드(Quartz 등)와 장식 처리가 겹치면 GPU 장식이 자동으로 꺼질 수 있습니다(설정창에 이유가 나옵니다).
- 리눅스·맥(네이티브 유니티)에서는 설치 없이 안내만 하고 꺼집니다. Windows 전용입니다.

문제가 있으면 맵·곡 시간·어떤 동작(시작/죽음/다시 하기/곡 끝/에디터)인지와 `Player.log`(`[StutterFix]` 줄)를 함께 남겨 주세요.
