# 화면 효과 페이지 (ReShade 같은 기능) 설계

설정 창에 "화면 효과" 페이지를 따로 두고, 게임 화면에만 후처리 효과를 건다. **원래 게임 화면을 바꾸는 기능이라 전부 기본 꺼짐.**
클라우드에서 쓴 설계다. 빌드·측정은 PC 에서.

## 이미 있는 것 (새로 만들 필요가 적다)

1. **게임에 들어 있는 CameraFilterPack 셰이더**: `Shader.Find("CameraFilterPack/...")` 로 바로 쓸 수 있다(`LowEnd` 의 선명하게가 `CameraFilterPack/Sharpen_Sharpen` 을 쓴다).
   게임에 실제로 들어 있는 이름 목록부터 뽑는다(`Resources.FindObjectsOfTypeAll<Shader>()` 를 개발자용 명령으로). 색, 비네트, 색수차, 필름 그레인, 블러 등이 있으면 셰이더를 새로 만들 필요가 없다.
2. **셰이더 묶음을 모드에 넣는 길**: `fsr/` (FSR 1, `BuildFsr.cs.txt` 로 유니티 6000.3 에디터에서 AssetBundle 을 만들고 DLL 에 넣어 `AssetBundle.LoadFromMemory`). 새 셰이더도 같은 길로 묶는다.
3. **게임 화면만 따로 다루는 자리**: 플레이 중 게임은 카메라 3개를 `scrCamera.camRT` 한 장에 그린 뒤 사각형으로 낸다(`LowEnd` 해상도 낮추기·`Fsr` 이 쓰는 곳). 여기에 걸면 UI(HUD, 설정 창)는 그대로 선명하다.
   에디터·메뉴처럼 camRT 를 안 쓰는 화면에서는 걸지 않거나, 본 카메라에 따로 건다(나중).

## 효과 (먼저 할 것부터)

| 효과 | 셰이더 | 비고 |
|---|---|---|
| 색감: 채도·대비·밝기·색온도·감마 | 한 패스로 새로 (가벼움) | 가장 쓸모 있음 |
| 선명하게 | 이미 있음 (CameraFilterPack Sharpen / FSR RCAS) | 화면 효과 페이지로 옮기기만 |
| 비네트, 필름 그레인, 색수차 | CameraFilterPack 에 있으면 그것, 없으면 색감 패스에 합침 | |
| 블룸 | 게임에 블룸 이벤트가 있다(맵 연출). 맵 블룸과 겹치지 않게 | 무거움, 나중 |
| 안티에일리어싱 (FXAA) | 새로 (한 패스) | 타일 가장자리 |
| LUT (색 보정 표 이미지) | 새로 | 사용자가 LUT 파일을 넣게 |

AO·전역 조명·피사계 심도는 깊이 정보를 쓰는 효과라 2D 인 이 게임에서는 의미가 없어 넣지 않는다.

## 규칙

- **효과 여러 개는 한 패스로 합친다**(색감 + 비네트 + 그레인 + 색수차). 패스 하나마다 화면 전체를 한 번 더 읽고 쓰므로 3440x1440 에서 비싸다.
- 효과마다 GPU 시간을 PresentMon(`MsGPUBusy`)으로 재서 설정 창에 대략 비용을 적는다.
- 맵 연출(필터 이벤트, 블룸 이벤트)과 겹칠 때 어느 쪽이 먼저인지 정한다: 맵 연출 → 화면 효과 순.
- 미리 설정(프리셋) 몇 개 + 직접 조절. 설정은 모드 설정에 저장.
- 끄면 원래 경로 그대로(카메라 대상·셰이더 원래대로). `Main.Unload` 에 되돌리기.
- ReShade 셰이더 코드는 라이선스가 제각각이라 **복사하지 않는다.** 원리(공식)만 참고해서 새로 쓴다. 넣는 셰이더의 라이선스는 `fsr/license.txt` 처럼 같이 둔다.
- ReShade 자체를 깐 사용자는 모드가 알아채서(게임 폴더의 ReShade dll) 로그·모니터에 표시만 한다.

## 첫 단계

1. 개발자용 명령으로 게임에 든 셰이더 이름 목록 뽑기.
2. 색감 한 패스 셰이더 만들어 fsr 과 같은 방법으로 묶기, camRT 에 걸기.
3. 끔/켬 GPU 시간 재기, UI 가 그대로인지 확인(`shot` 캡처).
4. 설정 창에 "화면 효과" 페이지(Linear/Raycast 방향, 기존 페이지와 같은 모양).
