# StutterFix 2.7.0 업데이트

- **프레임 늘리기(실험)**가 더 고르게: 모니터 갱신에 맞춘 출력, 조밀한 움직임 찾기, 공 궤도 보간, 무거운 구간의 빈칸 줄이기. **움직임 흐림(모션 블러)** 옵션도 추가했습니다.
- 첫 곡 시작 때 소리만 나오고 화면이 약 4초 멈추던 문제를 고쳤습니다.
- "화면 효과"가 **쉐이더**로 바뀌었습니다: 켜짐 탭, HDR·필름 톤, 20종 추가, 설정 공유 코드.
- **연출 끄기**: 지금 맵이 쓰는 효과를 위에 모아 보여 주고, 한 번에 끄기·되돌리기를 추가했습니다.
- 게임 3.4 알파에서 꺼져 있던 장식 즉시 이동 최적화를 복구했습니다(Arche 무거운 구간의 63~69ms 끊김 제거).
- **새 기능은 전부 기본 꺼짐**입니다.

자동 업데이트를 켜 둔 분은 설치 알림 후 게임을 다시 켜면 적용됩니다(프레임 늘리기는 꼭 다시 켜야 합니다).
수동 다운로드·상세 패치노트: https://github.com/pding4569/StutterFix/releases/tag/v2.7.0
문제가 있으면 설정 창의 `로그 내보내기`로 만든 ZIP을 보내 주세요.
