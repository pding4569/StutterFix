# StutterFix 2.8.0 업데이트
- **곡 중 무작위 끊김 감소**: 메인·렌더 스레드 우선순위를 함께 높입니다. 같은 PC의 HELLO 전곡에서 30ms 넘는 프레임 12·20개 → 0·1·2개였습니다.
- **성능 범위**: 정식 ZIP HELLO 전곡은 2.7.3 195 FPS · 2.8.0 192 FPS, 양쪽 끊김 0으로 FPS 변화가 거의 없었습니다(서로 다른 시점의 실행 확인, 성능 A/B 아님). 장식이 몰린 Arche 구간에서는 별도 기능 A/B로 약 +1~8%를 확인했습니다(색·회전 252~273초, 마무리 257.7~278.8초·2560×1440·120Hz, 합산 불가).
- **히트음 예약 묶기·화면 밖 파티클 멈추기 기본 켬**: 히트음을 0.5초씩 묶어 예약해 Arche 전곡 441 → 470 FPS(+6.6%, 끊김 0). 소리 타이밍·음량이 아주 조금 달라질 수 있어 저사양 페이지에서 끌 수 있습니다.
- **장식·타일 처리 가볍게**: 위치·회전·크기·색 계산과 투명 장식의 이미지 교체, 화면 밖 타일 색·발광 처리를 줄였습니다. 기본 켬입니다.
- **맵 다시 열기·실험 탭**: 디스크 캐시는 기본 켬입니다. 플레이의 다섯 번째 실험 탭으로 옮긴 문자열 재사용·로딩 업로드 예산·태그 색인·장식 목록 정리 생략은 새 설정에서 기본 꺼짐이며 저장값은 유지합니다.
- **쉐이더 내 프리셋**: 쉐이더 > 켜짐에서 이름을 붙여 최대 12개 저장·적용·덮어쓰기·삭제하고, 모두 끄기 뒤 다시 켜기로 직전 설정을 복원해 일일이 켜고 끄는 수고를 줄입니다.
- **게임 업데이트 주의**: Unity 6000.3.25f1 입력 API 변경에 대응했으며, 별도로 Quartz 등 일부 모드는 예외와 큰 프레임 저하를 일으킬 수 있습니다(확인된 Quartz 입력 패치 문제는 StutterFix와 별개이며 모드 폴더에서 Quartz를 꺼 정상 진행 확인).
자동 업데이트 설치 알림 후 게임을 완전히 껐다 켜 주세요. 문제는 설정 창의 `로그 내보내기`로 만든 ZIP을 보내 주세요.
