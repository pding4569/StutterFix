## 2단계: 진단 명령 (AutoTest, 개발/자동 시험 빌드만)

`occlude census` : 지금 프레임에서 메인 카메라(`Camera`) 기준으로
- 가리개 후보: SpriteRenderer, 장식(GpuCensus.IsDecoration), 켜짐·보임, 셰이더 Sprites/Default 또는 Sprites/Tile(일반 알파 혼합, 키워드 없음 또는 점 샘플링만), renderQueue 3000, blendMode 없음·blendModeEffect 꺼짐, maskInteraction None, 색 알파 1(SpriteRenderer.color.a 와 재질 _Color.a 모두), 그림 전체 불투명(또는 스프라이트 rect 안 칸이 모두 불투명), 스프라이트 4꼭짓점을 화면으로 바꾼 볼록 사각형이 카메라 화면 4모서리를 모두 포함(회전 고려, 여유 1px).
  Tile(반복)은 반복 범위 전체가 덮는지로 판단. 메시가 Tight 여도 불투명이면 덮인다.
- 가려지는 것: 같은 카메라에서 정렬이 **엄격히 앞선**(sortingLayer 값, sortingOrder 가 더 작음) 렌더러. 같은 (층, 순서)는 동점 규칙이 복잡하므로 건드리지 않는다. renderQueue 다른 것, SpriteMask, 스텐실을 쓰는 것(마스크 상호작용 있음은 숨겨도 되지만 SpriteMask 자체는 절대 숨기지 않음), 다른 카메라 레이어는 제외.
- 출력: 가리개 수, 가장 아래 가리개 이름/정렬, 가려지는 장식 렌더러 수·그 화면 면적 합(화면 장 수), 가려지는 비장식(타일·행성 등) 수 따로.

`occlude hide on|off` : 매 프레임(Camera.onPreCull, 메인 카메라일 때만) 위 판단으로 가려지는 **장식** 렌더러에 forceRenderingOff=true, 끌 때 원래 값 정확히 복원. 매 프레임 할당 0, 판단 비용 로그(평균 µs).
SpriteMask/스텐실 쓰는 렌더러, 가리개 자신, 정렬 동점은 건드리지 않는다.
