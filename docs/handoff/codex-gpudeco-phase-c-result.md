## 시너지2 — 연구 후보

- `HiddenDecoSynergy`: 정확한 일반 이미지 형식, 실제 InvisibleSkip 대기 목록, 히트박스0·마스크아님·타일에 붙지 않음·유효한 시차·사전검사 비활성·GPU 미소유일 때만 적용한다.
