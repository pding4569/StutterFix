# 코덱스 작업: 2D 깊이 가림(Z-cull) 상한 측정 도구 (2026-11-13)

작업 폴더 `E:\StutterFixWork\wt-v14prod` (브랜치 claude/adofai-renderer). 커밋·푸시·게임 실행·설치 DLL 교체 금지(Claude 가 한다). 한국어로 보고.

## 배경 (왜)
GPU 병목 장면(HELLO 50초, DD 55초, 7777 120초, Arche 262초)은 반투명 장식이 프레임마다 화면 약 50~200장 분량을 덧칠하는 것이 비용이다.
이전 `occlude`(Occlude.cs, codex-20261110b-result.md)는 "화면 전체를 덮는 완전 불투명 장식"만 찾아 0개였다.
이번 아이디어는 **픽셀 단위**다: 장식의 텍셀 알파가 정확히 1.0 이고 색 알파가 정확히 1 이며 일반 블렌드(SrcAlpha, OneMinusSrcAlpha)이면,
그 픽셀은 뒤의 모든 것을 정확히 덮는다(dst = src*1 + dst*0). 앞에서부터 이런 픽셀에 깊이를 써 두면(깊이 선행 패스) 뒤 장식의 그 픽셀은 하드웨어 early-Z 로 아예 실행되지 않는다.
같은 샘플러·같은 UV 로 같은 값을 읽으므로 판정이 정확하다(밉맵 없음, 쌍선형이면 4텍셀 모두 255 일 때만 1.0).
**먼저 실제 장면에서 이렇게 잘리는 덧칠 비율(상한)을 잰다.** 크면 GPU 장식 렌더러/원본 경로 제품화, 작으면 폐기.

## 만들 것 (DEV || AUTOTEST 전용, 제품 빌드에 들어가면 안 됨)
자동 시험 명령 `zcull census` — 일시정지 상태에서 호출. 메인 카메라("Camera", Occlude.cs 와 같은 판정) 한 프레임에 대해:
1. 카메라가 실제로 그리는 렌더러를 **그리기 순서대로** 모은다. 정렬 규칙은 저장소에 이미 있는 것을 재사용(Occlude.cs/OccludePolicy.cs, GpuCensus.cs, DrawCollapsePolicy.cs, LiveDecoRenderer, 메모: 정렬층→순서→거리→셰이더 ID→재질 ID). 동점이 모호하면 그 묶음은 가리개에서 빼고 보수적으로 센다.
2. 가리개 후보 판정(렌더러 단위, CPU): Occlude.cs 조건 1~4·6 과 같되 "화면 전체를 덮음"(8번)은 빼고, 텍스처 불투명 사전 판정(5번)도 빼도 된다(셰이더가 픽셀마다 판정). 일반 블렌드가 아닌 것(가산·곱·Grab 혼합 모드·blendModeEffect·마스크·SortingGroup·스텐실 쓰는 셰이더)은 가리개가 아니다. GpuDeco 가 소유한 장식은 원본 렌더러가 꺼져 있으니, GpuDeco 끈 설정(rlNR)에서 재는 것이 기준.
3. GPU 측정(카메라 해상도 RT 에, CommandBuffer 로, 실제 카메라 렌더와 별개로 한 번):
   - 깊이 RT 를 지우고, 가리개를 **앞에서부터(역순)** `DrawRenderer(renderer, zPrepassMat)` 로 그린다. 셰이더: _MainTex(스프라이트 텍스처는 SpriteRenderer 가 넘기는 것) 를 원래 셰이더와 같은 UV·샘플러로 읽어 `a*color.a < 1.0` 이면 discard, 아니면 깊이에 그 렌더러의 순번 z 를 쓴다(ZWrite On, ZTest LEqual). 순번 z 는 렌더러마다 `cmd.SetGlobalFloat` 로.
   - 세기 패스: 모든 렌더러를 순서대로 다시 그리되 같은 z 로 **ZTest Less**(앞 가리개가 없는 픽셀만 통과), 가산(One One)으로 float RT 에 1 을 더한다 = 살아남는 조각 수. 같은 것을 ZTest Always 로 한 번 더 = 전체 조각 수. 알파 0 픽셀도 원래 그려지는 조각이므로 discard 하지 말고 센다.
   - 두 RT 를 AsyncGPUReadback 으로 합계(또는 GPU 축소)해서 로그: `[zcull] renderers=N occluders=K fragments_total=F fragments_alive=A culled=%`, 상위 20개 렌더러별(이름·정렬·전체/잘린 조각), 가리개 상위 10개(덮은 픽셀 수).
4. 메인 스레드 한 번만 비용이 들어도 된다(진단). 매 프레임 비용 0, 끝나면 RT/재질 해제. Main.Unload 정리.
5. 셰이더는 기존 진단/RunLod/GpuDeco 셰이더 번들 빌드 방식을 그대로 따라 추가한다(작업 폴더에서 번들 만드는 법을 찾아 문서화된 대로).
