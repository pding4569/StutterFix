## 작업 A: 설정창에 "?? ?? ?? ????"로만 보이는 항목 (먼저, 작다)

설정창의 한 기능 줄이 제목 "?? ?? ?? ????", 설명 "?? ??? ??? ??? ?? ??? ?? ??? ?????."로 보인다(스위치는 꺼진 상태, "그래픽 미리 준비"와 "고급 필터 빠르게 끄기" 사이, 그래픽/저사양 쪽 페이지).
원인 후보: (1) 소스 파일에 한글이 `?`(0x3F)로 저장된 문자열이 들어갔다(Codex 가 만든 파일에서 이미 한 번 있었다: WasteProbe.cs). 소스 전체에서 한글 리터럴 자리에 연속한 `?` 가 들어간 곳을 찾는다
`grep -rnP '"[^"]*\?\?[^"]*"' --include=*.cs .` 후 UI 문자열(SettingsWindow.cs 의 `T("…","…")` 호출) 중심. (2) 폰트에 없는 글자.
고친다: 원래 의미(주변 항목·문서·git 이력 `git log -S`, 영어 문구에서 추정)를 복원하고, 같은 유형이 다른 곳에도 있으면 전부 고친다. `.cs` 는 UTF-8 BOM 으로 저장한다.
검증: 자동 시험 `ui <페이지>.<탭>` + `shot <이름>` 으로 해당 페이지를 캡처해(AGENTS.md "설정 창 디자인" 절) 글자가 정상인지 확인, 한/영 모두. `[UI 잘림]` 경고 0.
재발 방지: 빌드 후 `.cs` 에 `T("?` / 연속 `??` 한글 자리 `?` 가 있으면 경고하는 간단한 검사(개발용 스크립트 `tools/` 아래)를 추가한다.

## 작업 B: 인게임 필터별 GPU 시간 측정

게임의 카메라 필터(`CameraFilterPack_*`, `OnRenderImage`)가 GPU 를 얼마나 쓰는지 필터 종류별로 잰다. CPU 시간은 이미 작다(호출당 6~9µs). GPU 시간이 목표다.
- 방법: D3D11 타임스탬프 쿼리(`GPU Disjoint` + timestamp)를 필터의 `OnRenderImage` 앞뒤에 건다(Harmony prefix/postfix, 개발용). 쿼리는 비동기로 수 프레임 뒤에 읽고(GPU 대기 금지), 필터 종류별로 합·호출 수·평균 µs 를 집계한다. 유니티에서 쿼리를 직접 만들기 어려우면 `FrameTiming`/`CommandBuffer` 의 `BeginSample`이 아니라 네이티브(`native/sfnative`)의 플러그인 이벤트로 타임스탬프를 찍는 방법을 쓴다. 보간 코드(`framegen*`)는 건드리지 말고 별도 파일로.
- 자동 시험 명령 `filtergpu on|state|off|reset`.
- 측정 맵(보간은 `FrameGenOutside=0`): HELLO 2026(필터 많음, 곡 전체), Arche, Windflower. 3440x1440(모니터가 꺼져 해상도가 바뀌면 그 값을 기록).
- 결과: 필터 종류별 표(등장 곡 시간 비율, 켜진 프레임당 평균 GPU µs, 곡 전체 GPU 시간 합), 동시에 켜진 필터 수 분포, 프레임 전체 GPU 시간 대비 비중.

## 작업 C: 비싼 필터를 싸게 (B 결과로)

B 에서 상위 3~5개(곡 전체 GPU 시간 합 기준)를 골라 각각 아래를 시도한다. 화면 차이는 **같은 프레임에서 원래 필터 출력과 대체 출력의 최대 채널 차이와 PSNR** 로 숫자로 남기고, 눈에 띄지 않는 것(예: 최대 차이 ≤ 2/255 또는 PSNR ≥ 45dB, 기준은 문서에 적는다)만 채택한다. 채택하면 기본 **끔** 설정으로 둔다.
1. 낮은 해상도에서 실행: 블러·글로우 계열을 반해상도로 처리하고 확대(원래 필터의 임시 RT 크기/중간 패스 해상도를 줄이는 방법도 가능한지 필터 소스 `CameraFilterPack_*` 의 `OnRenderImage` IL 로 확인).
2. 같은 결과를 내는 더 싼 구현(샘플 수 감소, 불필요한 임시 RT·복사 제거, `Graphics.Blit` 두 번 → 한 번).
3. 필터 하나가 이미 같은 프레임의 다른 필터와 합쳐질 수 있는지(결과가 ±1/255 안이면).
각 대체는 `Main.Unload` 에서 되돌리고, 설정 UI 문구(한/영)를 추가한다(작업 A 와 같은 인코딩 주의).
성능 A/B(4판 이상, 같은 세션 ABBA): 곡 평균 FPS, GPU 평균 ms, `[임무30]` 30ms 초과 프레임 수.
이득이 작으면(GPU 평균 0.1ms 미만, FPS 변화 없음) 채택하지 않고 숫자만 적는다.
