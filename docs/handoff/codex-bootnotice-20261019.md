# Codex 작업 AA: boot.config 초기화/변경 시 "한 번 다시 시작" 안내를 게임 켠 직후 눈에 띄게 — 게임 실행·Mods 설치·커밋 금지

결과: 코드 + `docs/handoff/codex-bootnotice-20261019-result.md`(**apply_patch UTF-8 BOM**, 한글 확인). 빌드 셋(Dev/Player/PlayerAuto) 오류 0, `tools/check-ui-encoding.py`·LoadCheck·CompatCheck 통과. 기본 동작(최적화)은 바꾸지 않는다. 안내만 추가.

## 문제 (Claude 실측, 알파 HELLO 전곡 3440×1440)
Steam 이 게임 업데이트·버전 전환(일반↔알파) 때 `boot.config` 를 초기화한다(`force-gfx-jobs=legacy` 사라짐, 옛 `force-d3d11-bitblt-model=` 복귀). 모드는 켜질 때 다시 쓰지만(`BootConfig.Apply`, 로그 "boot.config 수정: … (다음 실행부터 적용)") 엔진은 그 파일을 시작 때만 읽어서 **그 실행은 적용되지 않는다**. 초기화 직후 첫 실행: 평균 172 FPS / 1% low 85 / 12ms 초과 277개, 두 번째 실행(적용됨) 190 / 96 / 140개, 어제 알파 기준 197 / 100 / 76개. 사용자는 이를 모르고 "프레임이 안 나온다"고 느꼈다. 지금 안내는 설정 창 홈의 "재시작 권장" 카드(`RestartAdvisor.Reasons()` 의 "멀티스레드 그리기 설정을 바꿨습니다 (다시 켜야 적용)")뿐이라 설정 창을 열어야 보인다.

## 만들 것
1. `BootConfig` 에 상태 추가: `NeedsRestart`(이번 실행에서 파일을 실제로 바꿨고 실행 중인 엔진 값과 다름), `ResetByOutside`(Apply 가 바꿀 때 파일에 우리 키(`force-gfx-jobs`)가 없었거나 `force-d3d11-bitblt-model` 같은 옛 줄이 돌아와 있었음 = 외부(Steam)가 되돌린 경우) 구분. 사용자가 설정 창에서 스스로 토글해서 바꾼 경우(`StutterFix.cs:980` 의 `BootConfig.Apply(legacy, …)` 호출)와 구분해서 문구를 달리한다. 지금 엔진이 실제로 돌고 있는 값은 `BootConfig.Describe()`(실행 옵션 우선) 쪽 로직을 재사용.
2. **게임을 켠 직후 보이는 안내 카드**: 메뉴/첫 화면(곡 재생 중이 아닐 때, `!Hitch.Playing`)에서 화면 위쪽 가운데에 작은 카드(IMGUI, 기존 설정 창 디자인 규칙 — `CLAUDE.md`의 "설정 창 디자인": 아주 어두운 바탕, 상자 최소, 글자 `EEEFF1`/`8A8F98`, 모서리 6, 글자 많이 늘리지 말 것)를 최대 20초 띄운다. 곡 재생·에디터 편집 중에는 띄우지 않고, 사용자가 `닫기`를 누르면 이번 실행에서 다시 띄우지 않는다(설정 창 홈의 "재시작 권장" 카드는 그대로 유지). 문구(`T("한글","English")`): 외부가 되돌린 경우 — "Steam 업데이트로 그래픽 설정(boot.config)이 초기화됐습니다. StutterFix 가 다시 써 뒀지만 게임을 한 번 다시 시작해야 적용됩니다. 그 전에는 프레임이 낮게 나올 수 있습니다." / 사용자가 바꾼 경우 — "그래픽 설정을 바꿨습니다. 다시 시작하면 적용됩니다." 단추: `지금 다시 시작`(기존 재시작 경로 재사용: `RestartAdvisor` 의 재시작·"한 번 더 누르면 재시작"·저장 안 된 편집 보호·에디터 맵 다시 열기 그대로), `나중에`.
3. 로그에도 한 줄(`[그래픽 설정] 이번 실행은 boot.config 가 적용되지 않았습니다 (외부 초기화/사용자 변경)`).
4. **검증 도구**(DEV/AUTOTEST): 자동 시험 명령 `bootnotice show|state|reset` (카드를 강제로 띄움/상태 출력/닫음 상태 초기화), 기존 `shot <이름>` 캡처로 Claude 가 화면 확인. 실제 `boot.config` 는 건드리지 않는 모드(테스트 플래그만 세워 카드 표시) 필수: 시험 때 파일을 바꾸면 다음 실행 설정이 바뀐다.
5. 결과 문서에: 어디에 무엇을 넣었는지, 외부 초기화 감지 조건, 문구, Claude 가 돌릴 확인 순서(`bootnotice show` + `shot`, 정식 Player 빌드 로그에 안내 줄, 설정 창 홈 카드와 중복되지 않는지).

## 규칙
- 안내는 한 번에 한 개 카드, 자동으로 게임을 다시 시작하지 않는다. 최적화·부팅 설정 값 변경 로직(`BootConfig.Apply`)은 그대로.
- 한글 문자열 깨짐 검사 필수. 새 정적 이벤트/콜백은 `Main.Unload` 에서 해제.
