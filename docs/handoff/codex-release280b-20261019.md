# Codex 작업 W: 2.8.0 릴리스 문서를 최신 코드에 맞춰 고치기 — 소스 변경·게임 실행·커밋·태그·푸시 금지

대상: `docs/patch-notes-2.8.0.md`, `docs/announcement-2.8.0.md`, `README.md`(2.8.0 절), `CHANGELOG.md`(건드릴 필요 없으면 그대로), 그리고 `docs/handoff/codex-release280-20261019-result.md` 끝에 "수정 이력" 한 절. 모든 파일 UTF-8 BOM, apply_patch, 한글 확인. 버전 파일은 건드리지 않는다.

초안(코덱스 S 작업) 이후 코드가 바뀌었다. **코드에서 실제 값을 다시 확인하고** 다음을 반영:
1. **기본값 변경**(`docs/handoff/codex-cleanup280-20261019-result.md` 참고): `JsonStringPool`(맵 문자열 재사용), `AsyncUploadBudget`(로딩 업로드 예산), `TagIndex`(장식 태그 색인)은 **새 설정 기본 꺼짐 + 플레이 > 실험 탭**으로 옮겼다(이미 저장한 값은 유지; 이 셋은 2.7.3 정식에 없던 기능). `FastLane Compact` 생략도 기본 꺼짐(실험 탭). 패치노트·공지에서 이 셋을 "기본 켬" 으로 쓴 곳을 모두 고치고, 맵 불러오기 절은 **기본 켬으로 남은 것**(디스크 캐시 등)과 **실험 탭으로 내린 것**을 정확히 나눠 쓴다. `메인·렌더 스레드 우선순위`·TightLate·ColorFast·EulerMemo 는 기본 켬 그대로.
2. **설정 창 "실험" 탭**: 플레이 페이지 5번째 탭. 옮긴 옵션 목록은 위 cleanup 결과 표를 따른다(이름은 설정 창 문구 그대로). "설정 창의 새 실험 옵션" 표와 설명을 이에 맞게 고치고, "화면 이름에 (실험)이 붙어 있어도 현재 기본 켬" 문장은 이제 틀리니 삭제/수정.
3. **새 기능: 쉐이더 내 프리셋** (`docs/handoff/codex-fxslots-20261019-result.md`): 쉐이더 페이지 켜짐 탭의 "내 프리셋"(이름 붙여 최대 12개 저장·적용·덮어쓰기·삭제), `모두 끄기` 뒤 `다시 켜기`. 사용자 말로 짧게(왜 필요한지: 쉐이더를 일일이 껐다 켜지 않아도 됨).
4. **연구 플래그 정리**: 일반 사용자 빌드는 `groupstep-on`/`decobatch-on`/`decoengine-on`/`posfast-on`/`tightskip-on`/`evalmemo-on` 파일을 읽지 않는다 — 사용자 영향 없는 개발 정리이므로 패치노트에는 "개발자용" 한 줄만(또는 생략).
5. 공지(`announcement-2.8.0.md`)는 디스코드용 9줄 안쪽 유지: 쉐이더 내 프리셋 한 줄 추가, 맵 다시 열기 줄은 실제 기본 켬/실험 구분에 맞게 수정, 정식 ZIP 검증 결과(HELLO 전곡: 2.7.3 195 FPS · 2.8.0 192 FPS, 끊김 0)는 **"이번 버전은 HELLO 같은 타일 위주 맵에서 FPS 변화가 거의 없고 Arche 같은 장식이 몰린 구간(곡 252~273초, 약 +1~8%)에 이득이 있습니다"** 처럼 정직한 문장으로 한 줄(과장 금지; 숫자는 문서의 측정값만).
6. 알려진 주의: 게임 업데이트(Unity 6000.3.25f1) 뒤 일부 모드(예: Quartz)가 입력 API 변경으로 예외를 내고 프레임이 크게 떨어질 수 있음(우리 모드와 무관, 모드 폴더에서 해당 모드를 끄면 정상 — 로그로 확인된 사실만). 한 문장.
7. README 2.8.0 절도 같은 내용으로 맞춘다(측정값 그대로, 짧게).
