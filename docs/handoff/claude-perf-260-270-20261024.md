## render-merge 코드 준비 (Codex, 게임 시험 미실행)

독립 GPU 경로와 구간 메시를 같은 자원에서 ABBA 전환하는 후보, 시간표 누락의 실제 채널 검사, CPU fallback 정렬 경계, 픽셀/실제 Draw Calls/복원 게이트와 `tools/optimization/render-merge-steps.py`를 추가했다. 2.5초 layout 22개는 250~280·290~315초만 준비한다. 시간표와 실제 채널이 어긋나거나 범위를 벗어나면 CPU로 복구하고 실패한다. 기본 꺼짐·일반 Player 제외이며 전곡 적용 완료가 아니다.

**후보 FPS·픽셀·렌더러 수·끊김·게임 안정성은 아직 미측정**이다. 현재 `RENDERMERGE=ERROR reason=GAME_NOT_RUN`은 증거 미수집 상태다. 기존 측정값과 T2 이름 붙은 원시 기록은 변경하지 않았다. 현재 워크트리에 없던 etwstall의 `ETW_MONO_SYMS`/INC·LEAF 코드를 보완했으며, 새 기록은 별도 외부 주소 추출 장치가 있는 경우에만 선택 시험으로 만든다.

목표 차이: 6.1ms→220 FPS(4.545ms)는 최소 −1.555ms(−25.5%), 400 FPS(2.5ms)는 −3.6ms(−59.0%). 교체 그리기를 제거한 3.83ms에서도 400 FPS까지 −1.33ms(−34.7%)가 필요하다. 이는 새 후보의 예상 개선량이 아니다. 상세 구현·판정 범위·검증: `codex-render-merge-result.md`, 10줄 요약: `codex-render-merge-result-o.txt`.
