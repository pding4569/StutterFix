# StutterFix 2.7.2 업데이트

- 2.7.1 에서 FPS 제한을 풀고 프레임 늘리기 고정 배율(2~8배)을 쓸 때 진짜 FPS 가 떨어지던 문제를 고쳤습니다(같은 시험 142 -> 209 FPS).
- 60 FPS 제한처럼 진짜 FPS 가 낮을 때의 개선(멈춘 그림 0%)은 그대로입니다.

자동 업데이트를 켜 둔 분은 설치 알림 후 게임을 다시 켜면 적용됩니다(프레임 늘리기는 꼭 다시 켜야 합니다).
