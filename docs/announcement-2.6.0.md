# StutterFix 2.6.0 업데이트

- **프레임 늘리기(실험)** 추가: `주사율 맞춤 · 추천` 또는 `2~8배`를 선택할 수 있습니다.
- **화면 효과** 추가: 선명·또렷·네온 미리 설정, 글로우·Godrays·색감 등. 강도는 슬라이더와 숫자 입력으로 직접 조절합니다.
- 독점 전체 화면 전환·최소화 충돌과 FPS가 0으로 굳던 표시 문제를 수정했습니다.
- **새 기능은 전부 기본 꺼짐**입니다. 보간 시 화면 지연·깨짐이 생길 수 있으니 취향과 PC 성능에 맞춰 켜 주세요.

자동 업데이트를 켜 둔 분은 설치 알림 후 게임을 다시 켜면 적용됩니다.
수동 다운로드·상세 패치노트: https://github.com/pding4569/StutterFix/releases/tag/v2.6.0
문제가 있으면 설정 창의 `로그 내보내기`로 만든 ZIP을 보내 주세요.
