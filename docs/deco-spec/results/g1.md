## 픽셀 측정

`C`는 통합 GPU, `I`는 **같은 정지 상태/같은 채널에서 통합만 끈** 독립 GPU, `A`는 GPU live off 뒤 CPU 복원이다.
이는 그리기/복원 보조 대조다. 별도의 CPU 원본 완주나 전체 채널 애니메이션 의미 동일성까지 증명하지 않는다.
진단 중 의도한 live off는 비정상 전체 복귀 횟수에 세지 않았다.

대조 판의 정지 곡 시각은 262.008441초다. C/I와 C/A가 실패하고 I/A는 허용치 이내이므로,

`DrawCollapsePolicy.KeepAfterBarrier=true`의 기존 주석에도 262초 최대 차이 4가 남아 있다.
다만 이 옵션 하나가 유일 원인이라는 실험은 하지 않았다. 정렬/블렌딩/버퍼 경로 중 세부 원인은 미확정이다.
통합을 끄는 진단을 제품 수정이나 성능 개선으로 채택하지 않았다. 기본값 불변 조건 아래 해결되지 않은 픽셀 차단으로 기록한다.
